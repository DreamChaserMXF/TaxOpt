# 城市预设配置（省-市）

## 命名规则

- 文件名：**`省拼音-市拼音.json`**（直辖市为 **`直辖市拼音-市辖区名拼音.json`**，如 `beijing-beijing`）。
- **默认均按该市主流「市区」**缴存口径填写（社保/公积金各自公布的常见上下限）。
- **例外**：`zhejiang-hangzhou-counties` 表示杭州**桐庐、建德、淳安**等区县公积金下限与市区不同的常见口径，与 `zhejiang-hangzhou`（市区）并存。

## 使用方式

```bash
python main.py --list-presets
python main.py --preset jiangsu-suzhou both -m 20000 -b 100000
cp presets/shanghai-shanghai.json config.json
```

## 覆盖范围说明

本目录收录 **4 个直辖市**及**主要一二线城市**（省会、计划单列市、东部强地级市等）共 **42** 套预设，便于就近选用。数值来自公开政策报道与各地人社、公积金中心常见表述，**执行日期、险种类别与基数是否分险种**各地不同；本工具对社保采用 **单一基数** 简化，与实务不完全一致处已在下表「备注」点出。

**务必以参保地、缴存地当年正式文件为准**，并自行修改 `housing_fund_*_rate`、专项附加等。
