# 微信小程序开发进展与剩余事项

## 当前完成度

当前小程序已经从“基础骨架版”推进到“可用分析版”，主要完成了以下能力：

### 1. 输入能力

- 支持 `optimize` / `calc` 两种模式
- 支持全年名义收入、月薪、年终奖输入
- 支持优化目标切换
- 支持额外激励输入
- 支持股票激励多笔输入、增删改
- 支持城市预设加载
- 支持社保、公积金参数展开修改
- 支持专项附加扣除输入
- 支持基础输入校验和错误提示
- 城市预设已随小程序打包，可离线加载
- 计算逻辑已下沉到小程序本地，不再依赖 `/api/calculate`

### 2. 结果页能力

- 顶部方案横幅
- 名义收入展示
- 月薪/年终奖拆分展示
- 额外激励与股票激励摘要
- 8 张核心指标卡片
- 分项结果区
- 收入与税额构成区
- 年度收入构成图
- 月度到手趋势图
- 年终奖明细
- 股票明细
- 月度明细表

### 3. 历史记录能力

- 首页显示最近记录
- 独立历史记录页
- 支持查看结果
- 支持重新编辑
- 支持删除单条
- 支持清空全部

### 4. 分享导出能力

- 结果页支持保存长图
- 长图已包含核心结果、分项结果、收入构成等内容
- 已处理相册权限申请与失败提示
- 长图高度已做基础自适应

## 当前仍未完成

### 1. 结果页体验优化

- 长图版式仍可继续精修
- 结果页内容较长，仍可做折叠分组
- 月度明细仍偏表格思路，移动端可继续压缩

### 2. 历史记录体验优化

- 目前无筛选、搜索、分组能力
- 最近记录仍只支持简单列表
- 重新编辑返回首页的体验可继续优化

### 3. 分享能力扩展

- 目前只有保存长图
- 尚未支持微信分享卡片
- 尚未支持复制结果摘要

### 4. 真机适配

- 需要验证不同尺寸屏幕下的排版
- 需要验证相册权限弹窗在真机中的表现
- 需要验证长图生成的清晰度和截断情况

### 5. 发布准备

- 计算与城市预设不再需要配置 request 合法域名
- 若后续新增远程同步、在线更新或服务端导出，再单独配置 HTTPS 服务
- 需要走微信开发者工具与真机联调

## 建议下一步

建议后续优先级如下：

1. 真机验证保存长图和历史恢复链路
2. 优化结果页排版与折叠结构
3. 评估是否增加分享卡片
4. 准备提测与真机验收

## 备注

Python 版 `main.py` 仍作为算法真相源；小程序端维护一份等价 JS 实现，并通过一致性测试保护两端结果对齐。
