# 微信小程序联调与验收 Checklist

## 1. 环境准备

### 1.1 开发环境

- 已安装微信开发者工具
- 已安装 HBuilderX 或可正常编译 UniApp
- 已有可用的小程序 AppID
- 计算与城市预设无需 HTTPS 后端服务
- 如启用远程同步或在线导出，再配置合法 request 域名

### 1.2 离线计算环境

- 城市预设能从包内静态数据加载
- 本地计算返回 JSON 字段与网页版/API 一致
- 与 Python 核心计算的一致性测试通过

## 2. 开发者工具联调

### 2.1 首页输入能力

- 能看到 `税筹优化` / `收入计算` 两种模式
- `税筹优化` 模式下可输入全年名义收入
- `收入计算` 模式下可输入月薪、年终奖
- 可切换优化目标
- 可展开“其他收入”
- 可输入额外激励
- 可新增多笔股票激励
- 可删除单笔股票激励
- 可展开城市/社保参数
- 可修改专项附加扣除

### 2.2 本地计算

- 城市预设能正常加载
- 点击“开始计算”能在无后端服务时成功得到结果
- 计算异常时能看到错误提示
- 参数非法时能看到校验提示

### 2.3 结果页展示

- 顶部方案横幅展示正常
- 名义收入口径正确
- 月薪/年终奖展示正确
- 额外激励摘要正确
- 股票激励摘要正确
- 8 张指标卡片正常显示
- 分项结果区正常显示
- 收入与税额构成区正常显示
- 年度收入构成图正常显示
- 月度到手趋势图正常显示
- 年终奖明细正常显示
- 股票明细正常显示
- 月度明细可横向滚动查看

### 2.4 历史记录能力

- 首页能显示最近记录
- 点击“查看全部”可进入历史页
- 历史页能查看全部记录
- 历史页点击“查看结果”可进入结果页
- 历史页点击“重新编辑”可回到首页并回填参数
- 删除单条记录后列表立即更新
- 清空全部记录后列表立即更新

### 2.5 长图保存

- 点击“保存长图”能触发生成逻辑
- 首次保存时会请求相册权限
- 拒绝权限后能看到清晰提示
- 重新授权后能成功保存
- 长图内容不截断
- 长图文字清晰可读
- 长图金额显示正确

## 3. 真机验收

建议至少覆盖：

- iPhone 一台
- 安卓机一台
- 一个小屏设备
- 一个大屏设备

### 3.1 页面布局

- 首页无明显错位
- 结果页无明显错位
- 历史页无明显错位
- 横向表格可正常滑动
- 图表在不同屏幕宽度下仍可阅读
- 长内容滚动流畅

### 3.2 权限与系统行为

- 相册权限申请弹窗符合预期
- 已拒绝权限后再次点击保存能正确引导到设置
- 保存成功后能在系统相册里找到图片
- 图片分享给微信好友时清晰可读

### 3.3 结果正确性抽检

建议用网页版与小程序做同参数对照，抽检至少 5 组：

1. `optimize`，无额外激励、无股票
2. `optimize`，有额外激励
3. `optimize`，有多笔股票
4. `calc`，仅月薪+年终奖
5. `calc`，月薪+年终奖+额外激励+股票

每组至少核对：

- 名义收入
- 月薪
- 年终奖
- 到手现金
- 全年个税
- 公积金入账
- 年终奖税后
- 股票税后

## 4. 异常场景 Checklist

### 4.1 离线场景

- 断网时首页计算仍可正常完成
- 未配置 request 合法域名时不影响计算和城市预设
- 本地预设 slug 不存在时能给出清晰提示

### 4.2 输入异常

- 全年收入为空
- 月薪为空
- 年终奖为空
- 股票激励为负数
- 额外激励为负数
- 额外激励 + 股票激励 > 全年名义收入

### 4.3 数据异常

- 结果页没有 `stock_grants` 时不报错
- 结果页没有 `bonus` 时不报错
- 历史记录为空时页面能正常显示空态

## 5. 发布前检查

- 小程序名称、图标、简介已确认
- 若未启用远程能力，可不配置合法 request 域名
- 版本号已更新
- 页面标题已确认
- 隐私政策与必要说明已准备
- 真机长图保存已验证
- 历史记录链路已验证
- 关键结果与网页版抽检一致

## 6. 建议的执行顺序

建议按以下顺序验收：

1. 先在开发者工具完成离线计算主流程验证
2. 再做首页与结果页主流程验证
3. 再做历史记录与长图保存
4. 再做真机权限与排版验收
5. 最后做网页版对照抽检
